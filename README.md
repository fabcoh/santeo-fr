# santeo.fr

Renvoi de **santeo.fr** et **www.santeo.fr** vers le site Santéo : https://www.santeo.net

Ce dépôt ne contient qu'une petite page de renvoi, publiée par GitHub Pages avec un certificat (cadenas).
Les lignes mail de santeo.fr (MX, SPF) ne dépendent pas de ce dépôt et ne sont jamais modifiées par lui.
